# Alchemy3D Dual RTX A6000 — GHCR v1.1

**Inicio recomendado:** [README_GHCR.md](README_GHCR.md) para construir y publicar una sola imagen Docker desde GitHub Actions e iniciarla en Empirio con dos GPUs (Alchemy3D GPU0 / Qwen GPU1).

Este paquete deriva de `Alchemy3D_A6000_CUDA_Lab_v1_0`. Conserva la batería original de fusiones, controles, informes y endpoints autenticados. Los modelos grandes no están incrustados en la imagen.

**Estado de verificación:** scripts Python analizados por sintaxis; imagen CUDA no compilada ni ejecutada aún en una instancia NVIDIA.
